Project Requirements

Performance Requirements

The device using the application must be modern enough to run the application without it lagging excessively. The minimum specs are uncertain, but at least an I5 CPU is recommended as well as a decent integrated GPU or a separate, dedicated GPU to make sure that the application runs smoothly. In addition, the camera used for the application must have a capture rate of at least 30 fps to ensure that the user’s movements are being tracked properly.

Safety Requirements

While using Raider Trainer, the user must inspect their environment and ensure that they are in an open area where they are not likely to bump into any objects or walls. They must also ensure that they can fully raise their arm without hitting any overhead objects. There are no other safety concerns that could arise while using the application as the user is under no risk while interacting with the user interface.

Security Requirements

The application is entirely self-contained, relying on no outside internet interaction. This ensures that there is no way an outside source could easily interact with the main codebase. Before using the Raider Trainer, the user must enter their password and username to ensure that user workout data is not compromised. These usernames and passwords are stored in a local database allowing only the dedicated admin to have access to the user accounts. The image-capturing from the camera is also only used in the application with no data being sent to an external source. As such, the self-contained infrastructure of the application is extremely secure.
